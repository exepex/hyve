# ADR template

```
# ADR-NNN: <title>

Status: proposed | accepted | superseded by ADR-MMM
Date: YYYY-MM-DD

## Context
What forces are at play. Cite threat IDs (e.g. SB-01, PI-03) and requirements.

## Decision
What is decided, in one or two sentences.

## Consequences
What becomes easier, what becomes harder, what residual risk remains.

## Abuse cases
Which tests in docs/04-security/19-abuse-case-test-plan.md must pass for this decision.
```
